# Arkum Technologies | Personal Portfolio 🚀

Welcome to the personal technology and product portfolio of **Aryan Kumar**. This repository contains the source code for my modern, responsive, and interactive developer portfolio website.

## 🌐 Live Preview
 https://arkum.netlify.app

## 💡 About The Project
This website serves as the digital home for **Arkum Technologies**, my personal brand. It showcases my journey as a developer, my current technology stack, and the software products I am building to solve real-world problems. 

### Featured Products
* **AARK Resume Builder:** A modern platform for creating professional resumes.
* **AttendX:** An automated attendance management solution.
* **Akivo:** A secure and intuitive messaging application.
* **SkillMate:** A platform connecting students with practical learning opportunities.

## 🛠️ Built With
* **HTML5** - Semantic and accessible structure.
* **CSS3** - Custom styling, Glassmorphism, CSS Variables, and responsive design.
* **Vanilla JavaScript** - Intersection Observers for scroll reveals, sticky navigation, and parallax animations.

## ⚙️ Features
* **Glassmorphism UI:** Modern, premium translucent design elements.
* **Scroll Animations:** Smooth reveal animations using Intersection Observer API.
* **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop screens.
* **Functional Contact Form:** Integrated with Netlify Forms for direct message handling.
